## 2025年度总结

过了30岁的年龄，发觉时间流逝的速度加快了。2025年工作和生活都依然忙碌，而且生活的比重逐步加大，工作的边界从确定到模糊，有了更多的探索空间。

2025年去了天津、上海、杭州、福州。从3月份开始，我基本就陆续到上海常驻办公了，此后大多数时间都在上海。2025年也退了在北京居住了6年的房子。

2025年，大语言模型技术强劲发展，在 Coding Agent 的能力上基本每月都有新的进展，当然也在逐步影响整个行业，思考方式、干活方式都在改变。

2025年下半年，自己间断地尝试了远程办公的模式，这样对于家庭的责任也能实际地做出一些行动，给屋里添置了各类电器家具，为正式搬入新家做好了准备。2025年10月份正式搬入了新家。

整体上主要以工作为主，家庭相比前几年投入的精力和时间要相对大一些，但也整体不大，只是逐步倾斜。工作上可以分为上半年和下半年。

上半年，更多是一线项目的交付和客户日常的沟通。6月30日之前，完成了3个主要项目及若干维护项目的跟进。上半年，得益于 AI 的发展，我负责项目的一些编码工作也用了大语言模型辅助编程和分析疑难杂症，这个过程对于问题的解决确实起到了加速作用，而且个人也是一个学习的过程。不过至少在2025年上半年，编码过程中，人的思考和投入还是没有减少很多。相反，有时会投入更多时间，因为大语言模型会让你对一个问题分析得更为透彻；对于当前实现，人要去评审、决策。所以编码的语法、代码不用太花费时间，但是决策、评审更花费时间了。

下半年，更多是公司产品研发工作，也就是转向了内部，弱化了对外交付。这个变化其实也受到大语言模型能力突飞猛进的影响：过去难解的问题是不是可以用模型直接来做，过去难做的功能是不是可以尝试用 Coding Agent 直接来实现，等等问题都成为可能。基本上，下半年对于大语言模型可以说是 All in 了，所有的系统开发过程都 AI 化了，功能实现也接入了基础模型的能力，越做越嗨，比喝咖啡还精神振奋。因为脑子的想法，只要你敢于尝试，就可以借助 AI LLM 来帮你快速实现，看到一个可运行的程序反馈。从下半年开始，组内大家都逐步通过自然语言加 Agent 的方式来编程了，而且是模块级别、系统级别的，让全栈和全干变得不足为奇，前后端可以一起搞，而且不要那么多人，凡事更愿意和 Agent 沟通。大语言模型和具体的任务结合起来，让我觉得未来5到10年又是一个 AI 腾飞的时间窗口，而且这次可能持续时间更久、影响范围更广、渗透力更强。对于我们做程序开发相关的人群也提出了更大的挑战。凡事挑战与机遇共存，我们能做的就是积极拥抱变化，顺势而为，在变化中提升自我。

这一年，工作上最大的心理成长就是承担边界模糊的任务，自己要去思考、确定边界并拆分，同时推进，拿到反馈并校准。这个过程个人觉得有几个能力得到提升：一是对于主次矛盾的识别，因为资源有限，不可能都做；二是主要矛盾里的关键问题的识别，哪些作为主线继续投入，哪些搁置或砍掉，这要决策；三是迭代反馈的速度要快，暴露问题并识别、攻克主要问题，才能让资源获得最大化收益。我作为负责人，自己的心理关要过，因为人性总是趋利避害的，人总是寻求确定性带来的安全感。同时还要团队达成共识，朝着共同目标前进，这更有难度。所以说，AI 确实让我们加快了干活的效率，但是人性内在的局限，还有人与人之间的沟通、对齐，在当下依然是决定一件事最终能不能干得有价值、有意义、有效率的最大变量。

2025年也读了几本书：《天朝的崩溃》换一个角度看待事情，可能会引发你更深入的思考。《人类简史》《左耳听风》等。

综合这一年下来，工作和生活都进入了一个调整和深化的阶段，外部的变化会打破或者影响内在的稳定。很正常，30岁后的本来面对的事情就会更多、更细，保持一个稳定的个人内核是很考验自己的。所以你会看到有些人被不知不觉地磨平了，以看透了为由，从而放弃了对生活、对未来、对自己的那种好奇心，蠢蠢欲动的感觉、欲望感。这是很不值得的。我选择接受外围事情的变动，但是内心要定期问问自己到底要追寻什么。可能也会内耗，但会通过和更高认知的人去沟通、读书、运动、旅游去化解这些负面因素，提升思考的维度，保持一份好奇心和纯真的欲望。

2025年是调整爬坡的一年，是不确定因素更多的一年。但是这就是人生的体验吧，接受它并与之同行。
